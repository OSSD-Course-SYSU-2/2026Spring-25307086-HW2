# 📡 中山大学南校区（康乐园）饥饿感知系统 - V3 版本更新说明

欢迎来到**饥饿感知系统**的 V3 数字化重构版本！本次 V3 更新迎来了核心业务逻辑的重大突破。我们将开发重心聚焦于**“真实空间定位系统”**与**“动态天气感知系统”**的深度整合，让每一次的干饭决策都能真正做到“因地制宜、因天而变”。

---

## 🚀 V3 核心功能与架构亮点

### 1. 🛰️ 双重稳健性空间定位系统 (Spatial Location System)
本版本彻底打通了虚拟与现实的空间坐标，实现了高精度的距离演算：
* **真实 GPS 感知**：深度接入 `@kit.LocationKit`，通过 `geoLocationManager` 获取用户当前的真实经纬度（Latitude & Longitude），作为决策的中心起点。
* **数字孪生空间锚点**：针对中山大学南校区（康乐园）专属定制了空间矩阵。即使在室内 GPS 信号微弱，用户也可手动切换至“第一教学楼”、“丰盛堂”、“逸夫楼”等基准空间锚点。
* **高精度动态距离演算**：底层采用**半正矢公式 (Haversine Formula)**，实时计算当前位置与各个食堂/外卖点的物理距离，并以此作为决策权重（如雨天会大幅降低远距离店铺的抽中概率）。

### 2. 🌦️ 动态天气感知与异步状态同步 (Dynamic Weather Perception)
天气是影响大学生就餐决策的核心变量。V3 版本为此构建了完善的天候引擎：
* **实时气象联网**：通过 `@kit.NetworkKit` 接入实时天气 API，根据用户的定位实时拉取当下天候状态（如降雨、阴云、晴朗）。
* **异步状态精准同步**：彻底解决了网络请求时间差导致的 UI 错位 Bug（如文字显示多云，图标却是晴朗）。引入了全新的 `📡 探测中` 过渡状态，确保异步数据回传后，图标与文字实现 100% 深度绑定刷新。
* **时空灾备推演算法**：为应对校园网络波动，内置了离线天气推演引擎。当断网时，系统会根据当前时间（日/夜）与概率算法，智能模拟出“倾盆大雨”或“清朗夜空”等合理天候，确保决策链条不断裂。

### 3. 🎨 视觉降级防护与食欲唤醒 UI (UI/UX Optimizations)
在强化核心系统之余，我们也对边缘视觉体验进行了精致化重构：
* **暖色渐变护城河**：针对海外图库（Unsplash）常态化断链的问题，废除了会抑制食欲的冷色调与系统默认的“蓝色网格大方块”。全面引入了基于就餐类型（吃食堂、点外卖、出去吃等）动态生成的暖色线性渐变（如火锅红、芝士橘），在图片加载失败时无缝兜底，保证界面高级感。

### 4. 🗄️ V13 矩阵缓存强制升级与清洗 (Data Persistence)
* 将数据持久化读写版本号全面升级至 **`V13`**（`MyShopsMagazine_V13_MapSensors`）。
* 在生命周期 `aboutToAppear()` 中植入了强效数据洗涤引擎，能自动拦截并清洗历史缓存中残留的网络死链，从物理层面冲刷旧沙盒，确保新逻辑完美生效。
