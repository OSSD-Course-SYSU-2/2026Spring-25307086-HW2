# 🍱 SYSU-Food-Picker (康乐园美食审判台)

> **项目初衷**：今晚吃什么，这是一件大事！本项目初版旨在通过简单的随机算法，帮助中山大学康乐园（南校园）的同学们快速决定下一餐，解决每天由于选择过多导致的“决策疲劳”。

---

## 🌟 核心功能回顾 (V1.0 基础版)

在最初的设计中，我们构建了决策系统的雏形，实现了以下基础能力：
* **分类均衡随机**：确保四大分类（食堂、外卖、出去吃、泡面）概率相等，不偏袒任何一种干饭方式。
* **加权推荐算法**：引入评分机制，按 5:4:3:2:1 比例加权，确保高评价的店有更高概率被选中。
* **中大南校定制**：预设了松涛园、下渡路等周边真实美食数据，贴合实际生活场景。

---

## 🚀 重大版本更新报告 (V2.0 智能决策版)

在 2.0 迭代中，我们对决策引擎进行了深度的“智能化”重构，使其从一个简单的随机工具进化为具备“环境感知”能力的干饭助手。

### 1. 🌍 环境感知与时空算法 (CONTEXT-AWARENESS)
* **设计目的**：让 App 拥有“常识”。
* **功能实现**：
    * **天气补偿**：新增“雨天模式”。下雨时会自动降低“出去吃”的概率，并提升“点外卖”与“吃泡面”的权重。
    * **时空校准**：自动读取系统时间。针对 18:00 等食堂高峰期自动修正排队时长预测。

### 2. ⏳ 智能等待预测与递减机制
* **设计目的**：在效率与惊喜之间寻找平衡。
* **功能实现**：
    * **常识逻辑优化**：泡面固定 3-5 分钟，外卖锁定在 25-50 分钟合理区间。
    * **负反馈递减**：若用户因嫌等太久而点击“重新选择”，系统会记忆上次时值，确保下一轮生成的预测时长严格递减。

### 3. 💰 多维意图驱动与财务约束
* **设计目的**：根据用户当下的实际“贫富”状态和时间状态进行决策。
* **功能实现**：
    * **四象限偏好**：提供“综合考量、极限省钱、效率至上、美味优先”模式。
    * **硬性预算拦截**：引入渐进式预算滑块，开启后将自动封印超出预算的店铺。

## 🛰️ 终极进化报告 (V3.0 全自动时空感知版)

在 3.0 版本中，应用正式打通了物理世界的连接，引入了 LBS 地理位置服务与网络通信，彻底化身为硬核“干饭神器”。

### 4. 📍 真实 LBS 测距与智能打散算法 (LOCATION-BASED)
* **精准距离计算**：全面引入 `LocationKit` 与 Haversine 算法，实时计算并分行展示当前位置到餐厅的物理距离（如 `📍 300m`）。
* **场景化坐标锚点**：为特定场景绑定物理锚点（如泡面对应“宿舍”距离，外卖对应“小北门外卖柜”距离）。
* **智能打散防重叠**：独创 **SMART SCATTER** 算法。针对未填写坐标的店铺随机生成合理的微小偏移量，彻底消灭坐标碰撞导致的距离重合问题。

### 5. ☁️ 全自动气象联网感知 (NETWORKED-CONTEXT)
* **API 自动获取**：接入鸿蒙 `NetworkKit` 与真实天气 API，启动时自动读取康乐园实时气象，并以 **简体中文** 标签友好展示。
* **算法无感联动**：一旦云端识别为“雨天”，底层决策权重瞬间自动重构，无需用户任何干预。

### 6. ⏱️ 步行/等候双轨并行算法 (PARALLEL-TIME)
* **时间拆分显算**：将耗时严谨拆分为“步行时间”（按 80m/min 动态换算）和“等候时间”。
* **外卖并行逻辑**：引入基于真实经验的逻辑：点外卖时，步行下楼与骑手送餐同时进行，总耗时采用 `MAX(步行, 等候)` 计算，堂食则采用相加计算。
* **新增距离偏好**：权重阵列新增 **“距离”** 专属偏好，一键过滤远方诱惑，只选最近的美味。

### 7. 🛡️ ARKTS 极严谨重构 (STRICT-MODE)
* **消灭隐式 ANY**：全面迎战 ArkTS 严格编译器审查，补全 Interface 定义，保障工业级运行稳定性。
* **高维数据录入**：智能批量导入现已支持 `名称 分类 价格 [纬度] [经度]` 的五维数据解析。

## 🛠️ 技术栈与架构

* **开发语言**: ArkTS (HarmonyOS 声明式开发语言，严格类型安全)
* **UI 框架**: ArkUI (内置毛玻璃特效与物理弹簧动画)
* **系统能力**: NetworkKit (HTTP 通信), LocationKit (高精度定位)
* **持久化层**: PersistentStorage (确保个人饭单永不丢失)
* **核心逻辑**: 多目标优化决策算法 + 并行时间流计算
